    公式

    把 f(x) 拆成不同频率的正弦与余弦；每一组对应一个圆。

    ω₀ = 2π / T
    aₙ = (2/T) ∫−T/2T/2 f(u) cos(nω₀u) du
    bₙ = (2/T) ∫−T/2T/2 f(u) sin(nω₀u) du
    c = (1/T) ∫−T/2T/2 f(u) du
    Rₙ = √(aₙ² + bₙ²)
    φₙ = atan2(aₙ, bₙ)
    f(x) ≈ S(x) = c + ∑ Rₙ sin(nω₀x + φₙ)

    函数拟合时由谐波序号 n 自动换算角速度 ωₙ=2πn/10 rad/s；模拟时间 τ=10x/T。自由调整采用 θⱼ=ωⱼτ+φⱼ+δⱼ。每根棍的方向独立计算；改角速度保留当前角度和历史轨迹。
