# 黑白水境中的红花

打开 `index.html` 即可观看。这个文件包含全部运行代码、Shader 和两份原花纹理，可以离线双击打开，不需要安装依赖。摄像机和花朵都在水下；水面在头顶，花冠保持原姿态，花茎向下延伸。

## 使用

- **空格**：暂停 / 继续花瓣、水波、焦散和映像。
- **H**：进入 / 退出沉浸画面；**Esc**：退出沉浸画面。
- **参数**：展开 / 收起控制面板；手机采用可收起的底部面板。
- **更多**：原来的上 / 下一帧、恢复默认、完整场景图片导出、透明花朵图标导出。
- **保存预设 / 恢复预设**：保存在当前浏览器；JSON 按钮用于跨浏览器保存与导入。
- 点击或拖动画面上方的水面，或者按“滴落水滴”，可以添加扰动；无需操作，水也会持续运动。

调慢水波请使用 **Water Motion Speed**，它与原花的“光影流转速度”分别累计时间。网格调整模拟精度，空间尺度调整波纹疏密，振幅调整实际起伏，三个参数独立。

原来的花色、着色浓度、同步光纹、涟漪、焦散、微光、漂浮舒展、花蕊、脉络、花茎、色温、速度、大小、三个分辨率按钮、四种预设和全部导出 / 暂停功能都保留。新增 **Flower Scale 0.25×—3×**；原来的“居中花朵大小”也保留，两者相乘。放大时花朵整体向下避让水面，花瓣形状与运动公式不变。

## 本地预览与修改

已有 Node.js 18 或以上时，在这个文件夹运行：

```sh
npm start
```

然后访问 <http://127.0.0.1:8787/>。或者双击 `启动本地预览.command`。端口占用时可设置其他端口，例如 `PORT=8788 npm start`。

没有 Node.js 时也可直接双击 `index.html`，或使用 Python：

```sh
python3 -m http.server 8787 --bind 127.0.0.1
```

修改 `src/`、`shaders/` 或 `assets/` 后执行：

```sh
npm run build
npm run check
```

构建仅使用 Node.js 内置模块，没有 npm 依赖，也不需要 `npm install`。`index.html` 是构建产物，请编辑对应源文件后重新构建。

## 光学实现边界

你的原花是**基于纹理系数的实时 WebGL2 花面**，不是三维网格模型。这里完整保留它的形变、纹理和光照算法，用一个有世界坐标的竖直薄面承载；没有重新建模花瓣。花自身的明暗 / 遮挡来自原 Shader，外部投影阴影来自同一实时花面透明度。它能保留你原来的正面观感，但不具备未提供的花瓣背面、真实厚度和任意视角的完整三维自阴影。

水下摄像机看到的顶部红色映像是**水面内反射**。透过水面看上方灰阶光源使用水到空气的 Snell 折射、Fresnel 和全内反射判断。默认低视角下，大量区域会发生全内反射，折射强度因此主要作用于能透射的区域。没有把同一幅直接花像同时称为折射和镜面反射。

“水面微散射光纹”是独立的艺术化灰阶表层项，用于加强 Wallace 式水面可读性，可以降到 0；它不是严格的体积散射求解。花瓣上的焦散则来自实时折射光线的面积聚焦。当前实现是实时薄面光学与柔和轮廓阴影，不是路径追踪或完整流体 / 体积光求解。

## 质量与网站嵌入

桌面默认 256² 水网格、平衡质量；窄屏默认 128²、轻量质量。可选网格 64²—512²。质量档位分别调整花朵纹理和焦散纹理精度；原有分辨率按钮控制最终画布长边上限。高 DPI 最多使用 2× 设备像素，并受所选长边限制。图片导出使用所选长边，不受当前窗口大小限制。

在个人网站中可嵌入：

```html
<iframe src="/underwater-red-flower/index.html?embed=1"
  title="黑白水境中的红花" style="width:100%;height:100svh;border:0"></iframe>
```

`?embed=1` 隐藏界面。同源父页面可以用 `iframe.contentWindow.HomeBlossom.setActive(false/true)` 控制离屏启停。浏览器标签隐藏时也会暂停推进时间。本文档交付本地项目，未修改或发布你的个人网站。
