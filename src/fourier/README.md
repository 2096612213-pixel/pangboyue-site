## 圆环编辑

播放与暂停时，悬停圆环都会加粗、提亮；鼠标静止时也按每帧圆的位置更新高亮。播放中单击画布暂停；暂停后点击圆环打开参数浮框。拖动、双指缩放不触发暂停。圆环命中使用当前画布缩放和平移后的屏幕坐标，优先选择最近的圆周，再选择包含指针的最小圆。逐层对比使用各自分区内的圆。拖动超过 4 像素视为平移，避免拖动结束误开浮框。

浮框可调半径、独立角速度、相位、杆宽倍数、圆线宽倍数、圆透明度、颜色、启用状态，以及“更多”中的连续相位修正。修改角速度仍保持当前角度连续；轨迹保留。原参数表与浮框同步，参数表的圆编号可重新打开已禁用或零半径的圆。恢复播放、切换函数/视图、恢复参数会关闭浮框；Esc 和点击外部也可关闭。

导出参数版本为 3，新增 circleWidthMultiplier 和 circleOpacity，其余字段保留。长说明在工作界面隐藏，参数单位和无障碍名称保留。

## 缩放与合成曲线

缩放范围为 0.25～1000 倍，滑条、数字框、按钮、滚轮、双指与键盘共用相同上限。圆数上限为 128。

实线合成曲线与实时圆链共用 `motionEndpoint`，直接计算各连杆竖直分量之和。历史按参数不变的时间段记录半径、角速度、相位、连续相位修正、启用状态、直流偏移和周期的快照。调参只建立新段，不用新参数重画旧运动；仅绘制已经运动到的时间，逐层对比使用对应的前缀圆链。

曲线绘制不再连接每周期固定 2048 点的旧记录，而是在可见时间范围内重新求端点。步长由二阶导数上界 `M = Σ |R| (10ω/T)²`、画布比例、缩放和像素密度决定，利用直线插值误差界 `M·Δx²/8` 将几何连线误差控制在 0.15 个画布像素内。参数求值与圆链一致；有限像素显示仍有光栅化和浮点精度限制，不声称数学上的零显示误差。灰色目标函数虚线和淡色左侧端点轨迹保留原采样记录。

数值回归：`node scripts/check-fourier-curve.mjs`，覆盖 60/70/128 圆、1/100/1000 倍、逐层合成、零角速度和调参历史隔离。
