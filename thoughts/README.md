# 每周写一份 thoughts.md

周记正文按 `年份-W周数/thoughts.md` 存放。现有内容在 `2026-W39/thoughts.md`，对应 2026 年第 39 周。

下一周写作时，在网站项目根目录的终端运行：

```bash
node thoughts/new-week.mjs 2026-W40
```

命令会自动创建 `2026-W40/thoughts.md` 并把日期加入 `weeks.json`。以后只要把 `2026-W40` 换成实际的年份和周数即可；周数必须是两位数字。打开新建的 Markdown 文件写作即可，不要把 JSON 内容粘进终端。目录页会自动按周数从新到旧排列；`week.html` 是所有周记共用的阅读页面，不需要每周复制。

保存后将新增的 Markdown 文件与 `weeks.json` 一起提交、推送；托管平台部署成功后，网站上才会出现新的一周。只保存 Markdown 而不增加目录项，目录页不会显示它。

## 统一标题与悬浮阅读位置

周记正文使用统一的 Markdown 标题层级：

- `# 2026 年第 40 周`：周记大标题。
- `## 2026-10-02`：日期标题。
- `### 展览`：当天的小节标题（可选）。

共用的 `week.html` 会自动识别一至三级标题。向下滚动时，已经滚出正文顶部的当前标题按层级悬浮显示；进入下一个日期或小节时自动更新。点击悬浮标题可回到对应段落。长标题在悬浮栏内省略显示，正文保留完整文字。新周记沿用以上格式即可，无需单独添加脚本。

阅读位置的样式和逻辑分别维护在 `reading-headings.css` 与 `reading-headings.js`，所有周记共用。

## 图片折叠

有图片的周记会自动显示右下角的“折叠全部图片”按钮，滚动时始终可用。点击后收起本篇正文中的所有图片及空的图片段落，保留文字、标题和视频；再次点击可展开。每次打开周记默认显示图片，新周记无需额外配置。共用样式和逻辑在 `image-toggle.css` 和 `image-toggle.js`。
